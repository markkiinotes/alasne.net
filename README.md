# Alasne Platform

Alasne is a custom PHP digital commerce platform designed for CMS, e-commerce, multi-store management, automation, and future AI integrations.

## Current Status

- Custom PHP framework
- XAMPP local environment
- Composer autoloading
- Environment configuration
- PDO database connection
- Router
- Request/Response layer
- Controllers
- View engine
- Admin layout
- Admin dashboard

## Local Development

Local URL:

http://alasne.local

Project path:

C:\xampp\htdocs\alasne.net

## Setup

1. Install XAMPP.
2. Install Composer.
3. Create `.env`.
4. Run:

```bash
composer install
composer dump-autoload -o
}
